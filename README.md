# HR Dashboard - Demographic Overview

## 📊 Project Overview
This repository contains a Tableau dashboard designed to provide HR teams with a clear **demographic overview** of the workforce.  
The dashboard helps visualize diversity, employee distribution, and workforce composition across multiple dimensions.

## 🎯 Key Features
- **Gender Distribution**: Pie/Donut chart showing male, female, and other representation.
- **Age Groups**: Histogram grouped into ranges (20–30, 31–40, 41–50, 51+).
- **Education Level**: Bar chart displaying highest qualifications.
- **Ethnicity Breakdown**: Stacked bar chart highlighting diversity.
- **Years of Experience**: Line chart showing tenure distribution.
- **Employee Location**: Map visualization of workforce spread across regions.

## 🛠️ Tech Stack
- **Tableau Desktop / Tableau Public**
- Data source: HR dataset (CSV, Excel, or database connection)
- Optional: Tableau Server for sharing dashboards
